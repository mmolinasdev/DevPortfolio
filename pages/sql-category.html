Sobre esta categoría

Esta categoría reúne los talleres de SQL realizados sobre Oracle Database, avanzando desde consultas básicas hasta transacciones controladas con evidencia de auditoría.

El primer taller cubre el esquema oficial HR (Human Resources) de Oracle, trabajando filtros, funciones y JOINs. El segundo taller aplica SQL avanzado con un caso de ajuste salarial real, control transaccional y demostración de las propiedades ACID.
