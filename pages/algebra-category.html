Sobre esta categoría

El Álgebra Relacional es el fundamento matemático de las bases de datos relacionales y del lenguaje SQL. Define un conjunto de operadores que permiten expresar consultas sobre relaciones (tablas) de forma precisa y formal, sin depender de ningún motor de base de datos en particular.

Dominar álgebra relacional es clave para entender cómo piensa el optimizador de consultas internamente y para diseñar consultas SQL eficientes.

σ Selección — filtra filas π Proyección — elige columnas ⋈ Join natural — combina tablas × Producto cartesiano − Diferencia — negación ρ Renombre — resuelve ambigüedad ∪ Unión
