Prácticas de consultas sobre Oracle Database Sample Schemas

Sobre esta Categoría

Esta sección reúne las prácticas realizadas con SQL en Oracle Database, utilizando los esquemas de ejemplo oficiales de Oracle (HR – Human Resources). Se abordan desde consultas básicas de selección y filtrado hasta JOIN entre múltiples tablas, funciones de fecha, numéricas, de cadena y de grupo.

Base de datos utilizada: Oracle Database Sample Schemas — esquema HR (Human Resources). Tablas principales: EMPLOYEES, DEPARTMENTS, LOCATIONS, COUNTRIES, REGIONS, JOBS. Fuente oficial: github.com/oracle-samples/db-sample-schemas

Consultas Básicas SELECT

WHERE BETWEEN IN / NOT IN IS NULL / IS NOT NULL LIKE Variables de sustitución UPPER / LOWER LPAD / RPAD

Práctica enfocada en la cláusula WHERE con los operadores de comparación y lógicos más usados en Oracle SQL. Se exploran filtros por rango, listas de valores, valores nulos, patrones de texto y variables de sustitución interactivas. También se trabajan funciones de cadena como UPPER, LOWER, LPAD y RPAD.

Filtros con BETWEEN

BETWEEN filtra un rango inclusivo. Se puede invertir con NOT BETWEEN.

SELECT HIRE_DATE FROM EMPLOYEES WHERE SALARY BETWEEN 12000 AND 15000; SELECT HIRE_DATE FROM EMPLOYEES WHERE HIRE_DATE BETWEEN '01-ENE-12' AND '31-DIC-21'; SELECT HIRE_DATE FROM EMPLOYEES WHERE HIRE_DATE NOT BETWEEN '01-ENE-12' AND '31-DIC-21';

Filtros con IN / NOT IN

IN comprueba si un valor pertenece a una lista, evitando múltiples condiciones OR.

SELECT EMPLOYEE_ID, FIRST_NAME FROM EMPLOYEES WHERE DEPARTMENT_ID IN (90, 80, 100, 60); SELECT COUNTRY_ID, COUNTRY_NAME FROM COUNTRIES WHERE REGION_ID NOT IN (10, 20);

Filtros con IS NULL / IS NOT NULL

Para valores nulos no se puede usar = ni !=; se requiere IS NULL.

SELECT EMPLOYEE_ID, FIRST_NAME FROM EMPLOYEES WHERE MANAGER_ID IS NOT NULL; -- empleados con gerente SELECT EMPLOYEE_ID, FIRST_NAME FROM EMPLOYEES WHERE MANAGER_ID IS NULL; -- el CEO / sin gerente

Búsqueda de patrones con LIKE

% representa cero o más caracteres; _ representa exactamente uno.

SELECT FIRST_NAME FROM EMPLOYEES WHERE FIRST_NAME LIKE '%A%'; -- contiene 'A' SELECT FIRST_NAME FROM EMPLOYEES WHERE FIRST_NAME LIKE '%n'; -- termina en 'n' SELECT FIRST_NAME FROM EMPLOYEES WHERE FIRST_NAME LIKE '_o%'; -- segunda letra es 'o'

Variables de sustitución (& y &&)

Con &variable Oracle pide el valor en cada ejecución; con &&variable lo reutiliza en la misma sesión. Útil en SQL*Plus y SQL Developer.

SELECT * FROM EMPLOYEES WHERE LAST_NAME = '&&ln'; -- define una vez, reutiliza SELECT * FROM EMPLOYEES WHERE LAST_NAME = '&ln'; -- pide en cada ejecución SELECT * FROM EMPLOYEES WHERE &&condicion; -- sustituye la condición completa

Funciones de cadena: UPPER, LOWER, LPAD, RPAD

SELECT FIRST_NAME, UPPER(FIRST_NAME) AS "Nombre", LAST_NAME, LOWER(FIRST_NAME) AS "Apellido" FROM EMPLOYEES WHERE DEPARTMENT_ID = 90; SELECT LPAD('*', 1, '*'), RPAD('*', 2, '*'), RPAD('*', 3, '*'), RPAD('*', 4, '*') FROM EMPLOYEES;

SELECT con Operadores y Expresiones

Operadores aritméticos Alias (AS) Concatenación (||) Q-quote DISTINCT ORDER BY Valores NULL en cálculos

Exploración de las capacidades de proyección del SELECT: operadores aritméticos sobre columnas, alias con y sin comillas, operador de concatenación ||, la alternativa q-quote para cadenas con comillas simples, la cláusula DISTINCT para eliminar duplicados y ORDER BY para ordenar resultados.

Operadores aritméticos y alias

Las expresiones aritméticas sobre columnas generan nuevas columnas calculadas. Si algún operando es NULL el resultado es NULL (ver columna SALARY_PLUS_COMISSION para empleados sin comisión).

SELECT FIRST_NAME, LAST_NAME, SALARY, SALARY * 0.10 AS SALARY_10_PERCENT, SALARY * COMMISSION_PCT + SALARY AS SALARY_PLUS_COMISSION FROM EMPLOYEES;

Alias con comillas dobles y concatenación

Las comillas dobles permiten alias con espacios y caracteres especiales. El operador || concatena cadenas y columnas.

SELECT FIRST_NAME AS "Nombre", LAST_NAME AS "Apellido", FIRST_NAME || ' ' || LAST_NAME AS "Nombre Completo", SALARY AS "Salario", SALARY * 0.10 AS "Salario diez porciento" FROM EMPLOYEES;

Q-quote para cadenas con comillas simples

La sintaxis q'[...]' de Oracle permite incluir comillas simples dentro de una cadena sin necesidad de escaparlas con doble comilla simple.

SELECT FIRST_NAME || q'['s last name: ]' || LAST_NAME AS "Nombre Completo" FROM EMPLOYEES;

DISTINCT y ORDER BY

SELECT DISTINCT REGION_ID FROM REGIONS; -- elimina filas duplicadas SELECT SALARY FROM EMPLOYEES ORDER BY SALARY DESC; -- de mayor a menor

Funciones Numéricas y de Fecha

ROUND / TRUNC TO_DATE SYSDATE / CURRENT_DATE ADD_MONTHS NEXT_DAY LAST_DAY Aritmética de fechas DUAL

Práctica sobre funciones de una sola fila para manipulación numérica y de fechas en Oracle. Se usa la tabla DUAL para probar expresiones sin necesitar datos reales. Se trabajan redondeos, truncamientos, conversión de cadenas a fecha, obtención de la fecha actual, y funciones especiales de calendario.

ROUND y TRUNC numéricos

ROUND(n, d) redondea a d decimales (negativo redondea a la izquierda del punto). TRUNC(n, d) trunca sin redondear.

SELECT ROUND(555.923, -3) FROM DUAL; -- → 1000 SELECT TRUNC(45.923, 2) FROM DUAL; -- → 45.92 SELECT TRUNC(45.923, -1) FROM DUAL; -- → 40

TO_DATE y aritmética de fechas

TO_DATE convierte una cadena a tipo DATE usando una máscara de formato. Se puede sumar/restar días directamente a un valor DATE.

SELECT last_name, hire_date + 1 AS "Fecha Ajustada" FROM EMPLOYEES; SELECT TO_DATE('29/07/2002', 'DD/MM/YYYY') FROM DUAL; SELECT TO_DATE('29/07/2002', 'DD/MM/RRRR') FROM DUAL; -- RRRR maneja años de 2 dígitos

SYSDATE y CURRENT_DATE

SELECT SYSDATE FROM DUAL; -- fecha/hora del servidor SELECT SESSIONTIMEZONE, CURRENT_DATE FROM DUAL; -- fecha/hora de la sesión SELECT ROUND(SYSDATE - (TO_DATE('29/07/2002', 'DD/MM/YYYY')), 0) AS "DIAS_VIVIDOS" FROM DUAL;

TRUNC de fechas

TRUNC(fecha, 'MONTH') trunca al primer día del mes. Análogamente ROUND redondea fechas al inicio del período más cercano.

SELECT TRUNC(CURRENT_DATE, 'MONTH') FROM DUAL; SELECT ROUND(TO_DATE('15/05/2026', 'DD/MM/YYYY') - 2, 'MONTH') FROM DUAL;

ADD_MONTHS, NEXT_DAY y LAST_DAY

Funciones de calendario: sumar meses, obtener el próximo día de la semana y el último día del mes.

SELECT ADD_MONTHS(CURRENT_DATE, 1) FROM DUAL; -- mes siguiente SELECT NEXT_DAY(CURRENT_DATE, 'VIERNES') FROM DUAL; -- próximo viernes -- Último viernes del n-ésimo mes a partir de hoy SELECT NEXT_DAY(LAST_DAY((ADD_MONTHS(CURRENT_DATE, &mes))) - 7, 'VIERNES') FROM DUAL;

JOINs Avanzados y Funciones de Grupo

INNER JOIN LEFT JOIN RIGHT JOIN FULL OUTER JOIN Self-Join JOIN multi-tabla COUNT / MAX / MIN / AVG GROUP BY ORDER BY

Práctica avanzada sobre combinación de tablas con los distintos tipos de JOIN de SQL:92, incluyendo self-join para jerarquías (empleado → gerente) y JOIN entre cinco tablas encadenadas. Se incorporan las funciones de agregación COUNT, MAX, MIN y AVG junto con GROUP BY y ORDER BY para análisis estadísticos por departamento.

LEFT JOIN y RIGHT JOIN

LEFT JOIN devuelve todos los registros de la tabla izquierda aunque no tengan coincidencia en la derecha. RIGHT JOIN hace lo contrario: conserva todos los departamentos, incluso los sin empleados asignados.

-- LEFT JOIN: todos los empleados, con o sin departamento SELECT e.FIRST_NAME, e.LAST_NAME, d.DEPARTMENT_NAME FROM EMPLOYEES e LEFT JOIN DEPARTMENTS d ON e.DEPARTMENT_ID = d.DEPARTMENT_ID; -- RIGHT JOIN: todos los departamentos, con o sin empleados SELECT e.FIRST_NAME, e.LAST_NAME, d.DEPARTMENT_NAME FROM EMPLOYEES e RIGHT JOIN DEPARTMENTS d ON e.DEPARTMENT_ID = d.DEPARTMENT_ID;

FULL OUTER JOIN

Retorna todas las filas de ambas tablas, completando con NULL donde no hay coincidencia. Es la unión de LEFT + RIGHT JOIN.

SELECT e.FIRST_NAME, e.LAST_NAME, d.DEPARTMENT_NAME FROM EMPLOYEES e FULL OUTER JOIN DEPARTMENTS d ON e.DEPARTMENT_ID = d.DEPARTMENT_ID;

INNER JOIN encadenado (5 tablas)

Conecta EMPLOYEES → DEPARTMENTS → LOCATIONS → COUNTRIES → REGIONS para obtener la región geográfica de cada empleado.

SELECT e.first_name, e.last_name, r.region_name FROM EMPLOYEES e INNER JOIN DEPARTMENTS d ON d.department_id = e.department_id INNER JOIN LOCATIONS l ON l.location_id = d.location_id INNER JOIN COUNTRIES c ON c.country_id = l.country_id INNER JOIN REGIONS r ON r.region_id = c.region_id;

Self-Join (jerarquía empleado – gerente)

Una tabla se une consigo misma usando dos alias distintos. Con LEFT JOIN se incluye el CEO (sin gerente asignado).

-- INNER: excluye al CEO SELECT e.first_name || ' ' || e.last_name AS employee_name, m.first_name || ' ' || m.last_name AS manager_name FROM EMPLOYEES e INNER JOIN EMPLOYEES m ON e.manager_id = m.employee_id; -- LEFT: incluye al CEO con manager_name = NULL SELECT e.first_name || ' ' || e.last_name AS employee_name, m.first_name || ' ' || m.last_name AS manager_name FROM EMPLOYEES e LEFT JOIN EMPLOYEES m ON e.manager_id = m.employee_id;

Funciones de grupo: COUNT, MAX, MIN, AVG con GROUP BY

Las funciones de agregación operan sobre grupos de filas definidos por GROUP BY. ORDER BY ordena el resultado final.

SELECT COUNT(*) FROM COUNTRIES; -- total de países -- Salario máximo por departamento SELECT MAX(SALARY) FROM EMPLOYEES GROUP BY DEPARTMENT_ID; -- Estadísticas completas con nombre de departamento SELECT d.department_name, MAX(e.salary) AS max_salary, MIN(e.salary) AS min_salary, AVG(e.salary) AS average_salary, COUNT(e.employee_id) AS employees_quantity FROM DEPARTMENTS d JOIN EMPLOYEES e ON e.department_id = d.department_id GROUP BY d.department_name ORDER BY max_salary DESC;
